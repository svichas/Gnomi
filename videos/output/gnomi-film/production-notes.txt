EDITING
Open Gnomi.aive in Synthcut. Chapter markers identify all ten sections.
Audio clips are separate, so narration, music and effects remain adjustable.
Picture comes from the local deterministic 3D animation in source/film.js.

RENDERING (from the Gnomi repository root)
1. npm install --prefix output/gnomi-film/source
2. node output/gnomi-film/source/capture-app.mjs (requires the built app)
3. python3 output/gnomi-film/source/revise-inputs.py
   node output/gnomi-film/source/render.mjs stills
4. node output/gnomi-film/source/render.mjs video
5. ffmpeg -y -f concat -safe 0 -i output/gnomi-film/source/concat.txt -c copy output/gnomi-film/visuals.mp4
6. Open the Synthcut project and export the edit to Gnomi-master.mp4.
7. python3 output/gnomi-film/source/package.py
