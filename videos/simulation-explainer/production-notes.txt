RENDERING
From the extracted source/ directory:
  npm install
  python3 align.py
  python3 audio.py
  node render.mjs stills
  node render.mjs video
  ffmpeg -y -f concat -safe 0 -i concat.txt -c copy ../visuals.mp4
Then run python3 build-project.py to rebuild the dedicated edit, or relink the project with python3 relink.py and open Gnomi-simulation-edit-relocated.aive.
The delivered MP4 is assembled directly from the isolated picture/audio stems with
python3 finish.py. This avoids the shared editor switching projects during concurrent work.
The edit file follows Synthcut schema version 3 and is ready to open independently.
Requirements: Node, Python 3, FFmpeg/ffprobe, Chromium for playwright-core.
If Chromium is absent, set PLAYWRIGHT_CHROMIUM_EXECUTABLE to a local Chrome binary.
The renderer uses only local files and a loopback server. No website is captured.
Pinned versions: Three.js 0.180.0, playwright-core 1.64.1.
