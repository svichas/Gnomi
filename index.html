Open by design

Yours to run, read
and change.

No account and no hosted service. Gnomi is a desktop app you run yourself, and every line of it is on GitHub.

  • Free and open source.

    Licensed under AGPL-3.0. Use, study, modify and share it. If you distribute a modified version, or run one for others over a network, share its source too.

  • Local first.

    Projects, run history and evidence stay in a folder on your machine. Model inputs go only to the provider you configure, and web runs only reach the hosts you allow.

  • Bring your own model.

    Use Anthropic, OpenAI, Google or DeepSeek with your own key, or a local OpenAI-compatible server such as Ollama or LM Studio.

  • Inspect every run.

    Persona traits are sampled from a saved seed. Actions, screenshots and posts are recorded, and reports export as HTML, PDF, Markdown and JSON.

  • Script it.

    A command-line interface with JSON output covers audiences, estimates, runs and reports. Gate pull requests in CI, or let a coding agent run a study for you.

  • Honest about simulation.

    Findings are hypotheses, not facts about real users. Interpreting simulations explains what a run can and cannot tell you.

Get started

Two ways in.

Install the desktop app, or clone the repository and try the bundled demo without an API key.

Download the app

Installers for macOS (Apple silicon and Intel), Windows and Linux. Open Settings and add a provider key to start.

Latest release

The installers are not code-signed yet, so your system asks you to confirm the first launch. How to open it

Run it from source

Needs Node.js 24.15 or newer. Starts Gym, a small demo app with deliberately seeded UX defects.

git clone https://github.com/svichas/Gnomi.git
cd Gnomi
npm ci
npx playwright-core install chromium
npm run gym

Then send scripted personas through it from a second terminal, or open the app with npm run dev. Full quick start

Built in the open

Help shape Gnomi.

Gnomi is early and changes quickly. Bug reports, ideas and pull requests are welcome. Open an issue before starting anything large.

Inside the repository

A TypeScript monorepo: Electron and React for the app, Playwright for the browser, SQLite for the event log.

app/
Desktop shell and UI: audience editor, live graph, activity and reports.
engine/
Host process and CLI: projects, audiences and Figma import.
simulation/
Runtime: browser actions, provider routing, social rounds and reports.
demo/GymSite/
Demo app with a catalogue of seeded defects.
docs/
Technical design, behavioural model and guides.
